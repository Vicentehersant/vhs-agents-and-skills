# Styles taxonomy — design & branding styles canon

Owned/grown by `style-curator` (advisory + research modes append here; trend
reports in `trend-reports/` get folded in once a finding recurs ≥2 months).
Each entry: characteristics · typography/color/layout signature · when to use
/ tier signal · reference sites. Read only the entries the task needs.

## Minimalism
- **Characteristics**: extreme restraint, generous negative space, one focal
  element per screen, function drives every choice
- **Signature**: neutral/mono palette + one accent, sans-serif (Inter/Helvetica-
  class), grid strictly aligned, near-zero ornament, subtle motion only
- **When/tier**: premium/luxury tech, SaaS, portfolios wanting to signal
  confidence-without-noise. Tier signal: HIGH (restraint reads expensive) —
  but only if execution is precise; sloppy minimalism reads cheap/unfinished
- **References**: apple.com, linear.app, teenage.engineering

## Brutalism (web brutalism)
- **Characteristics**: raw, unstyled-looking, exposed structure, deliberately
  "undesigned" — anti-slick as a statement
- **Signature**: system fonts or heavy monospace, harsh black/white or clashing
  color, visible borders/underlines, no rounded corners, no shadows, layout
  looks unresolved on purpose
- **When/tier**: portfolios/agencies wanting to signal confidence + rebellion,
  art/culture/editorial. Tier signal: RISKY — reads "we don't care about
  polish" to corporate/enterprise audiences; strong fit for creative/indie
- **References**: brutalistwebsites.com (gallery), bloomberg.com/graphics
  (selective use), balenciaga.com (fashion-brutalist)

## Neubrutalism
- **Characteristics**: brutalism's rawness softened with playful color and
  usability — the "internet-native" evolution, popular in SaaS/dev tools
- **Signature**: thick black borders, hard offset drop-shadows (no blur),
  saturated flat colors, chunky rounded-ish shapes, bold geometric sans
- **When/tier**: dev tools, startups, Gen-Z consumer products wanting
  approachable-but-confident. Tier signal: MID — reads fun/modern, not luxury
- **References**: gumroad.com, figma.com community sites, supabase.com (partial)

## Glassmorphism
- **Characteristics**: frosted-glass panels floating over vivid/blurred
  backgrounds — depth via translucency, not shadow
- **Signature**: `backdrop-filter: blur()`, semi-transparent white/dark
  surfaces, thin light-catching borders, saturated gradient backgrounds behind
- **When/tier**: OS UI (macOS/iOS/Windows 11 chrome), dashboards, fintech/crypto
  wanting a "future" feel. Tier signal: MID-HIGH but dates fast (2021-22 peak) —
  use sparingly, on accent surfaces not whole layouts; watch AA contrast on
  translucent text (a11y-designer must verify worst-case background)
- **References**: apple.com/macos marketing pages, windows 11 UI

## Swiss / International Typographic Style
- **Characteristics**: grid-driven objectivity, typography as the primary
  design element, asymmetric-but-rigorous layout
- **Signature**: strict modular grid (columns visible in the rhythm), sans-serif
  (Helvetica/Akzidenz-class), red/black/white classic palette (not mandatory),
  large type-scale contrast, generous margins, little/no imagery decoration
- **When/tier**: editorial, cultural institutions, high-design agencies,
  publishing. Tier signal: HIGH — reads intellectual/considered
- **References**: are.na, walkerart.org, praxis.paris

## Memphis / Postmodern
- **Characteristics**: deliberately clashing, playful geometric shapes,
  squiggles, confetti patterns — 80s Memphis Group revival
- **Signature**: bright clashing palette (not tonal), organic squiggle/blob
  shapes as decoration, mixed typography weights, asymmetric confetti layout
- **When/tier**: youth brands, events, creative agencies, anything wanting
  "fun/irreverent". Tier signal: LOW-MID for corporate, but intentional choice
  for brands targeting Gen-Z/creative audiences — never accidental
- **References**: stripe.com (illustration system, restrained Memphis), mailchimp
  historic branding

## Y2K / Frutiger Aero revival
- **Characteristics**: early-2000s tech optimism — glossy, chrome, bubble
  shapes, gradient skies, translucent plastic
- **Signature**: chrome/glossy gradients, bubble-rounded shapes, cyan/silver/
  white palette, glow effects, pixel/chrome typography accents
- **When/tier**: nostalgia-driven consumer/fashion/music brands, Gen-Z targeting
  audiences who missed the era firsthand. Tier signal: NICHE — strong only when
  the audience explicitly skews young/culture-forward
- **References**: various fashion drops (see current Awwwards Y2K tag), heaven11
  studio work

## Editorial / Magazine-led
- **Characteristics**: content-first, large type hierarchy doing the work of
  navigation, generous whitespace, photography-led
- **Signature**: serif or high-contrast display type for headlines, strict
  vertical rhythm, pull-quotes, asymmetric image/text pairing, often broken/
  editorial grid (see `layouts-grids.md`)
- **When/tier**: publishers, thought-leadership content, premium consumer
  brands with a story to tell. Tier signal: HIGH when typography is precise
- **References**: nytimes.com/interactive, kinfolk.com, medium.com (baseline)

## Organic / Handcrafted
- **Characteristics**: warm, human, imperfect-on-purpose — counters the cold
  precision of minimalism/swiss
- **Signature**: hand-drawn or textured illustration, warm earthy palette,
  serif or humanist sans, rounded/soft shapes, grain/paper texture overlays
- **When/tier**: wellness, food/craft, education, small-agency/boutique brands
  wanting approachability over authority. Tier signal: MID — reads
  trustworthy/warm, not premium-luxury unless paired with precise execution
- **References**: houseoftoast studios, allbirds.com (partial), various Cargo
  portfolio sites

## Corporate-tech / SaaS-default
- **Characteristics**: the "safe" default — clean, gradient-accented,
  illustration-lite, conversion-optimized. What most B2B SaaS defaults to
- **Signature**: Inter/system sans, blue/purple gradient accents, rounded
  cards with soft shadow, abstract 3D-ish blob illustrations, generous but
  not extreme whitespace
- **When/tier**: B2B SaaS, dev tools, anything needing broad legibility fast.
  Tier signal: MID — safe, unmemorable at scale, use when speed/clarity beats
  differentiation, flag it as the "default trap" when a project wants
  to stand out and this is the unexamined instinct
- **References**: linear.app, vercel.com, stripe.com

## Luxury / Editorial-minimal
- **Characteristics**: minimalism's restraint plus tactile/premium material
  cues — the fashion/luxury-goods register
- **Signature**: serif display or high-contrast didone type, black/off-white/
  metallic palette, full-bleed photography, near-zero UI chrome, slow
  deliberate motion (not snappy)
- **When/tier**: fashion, high-end hospitality, premium real estate. Tier
  signal: HIGHEST — but unforgiving of any inconsistency, needs a11y-designer
  pass early (low-contrast text-over-image is the most common failure here)
- **References**: chanel.com, aman.com, cartier.com
